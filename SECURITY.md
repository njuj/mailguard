# Security Policy

## Reporting a vulnerability

mailguard is a defensive auditing tool. It reads only public DNS records and the public MTA-STS
policy — it sends no mail and stores no data about the domains it checks.

If you find a security issue in the tool itself, please report it privately via this repository's
**Security → Advisories → Report a vulnerability**, rather than opening a public issue.

## Scope

Use mailguard only on domains you own or are explicitly authorized to assess.
